# qBittorrent (static binary) YunoHost package

A YunoHost package for [qBittorrent](https://www.qbittorrent.org) using the
static `qbittorrent-nox` builds from
[userdocs/qbittorrent-nox-static](https://github.com/userdocs/qbittorrent-nox-static),
which work on Debian 12 (bookworm) and newer and include native I2P support.

## Purpose

Debian 12's packaged qBittorrent cannot reach 5.x (Qt6 / libtorrent 2.1 are
not available in bookworm). This package sidesteps the frozen distro
libraries by shipping the upstream static binary, wrapped with the usual
YunoHost integration: SSO-protected nginx vhost, systemd unit, logrotate,
backup/restore, and an I2P-first default configuration.

## Install

```
yunohost app install https://github.com/quartztester/qbittorrent-staticbinary_ynh
```

Requires a running I2P router exposing a SAM bridge (`java_i2p` or `i2pd`
YunoHost app with SAM enabled on `127.0.0.1:7656`).

See `doc/ADMIN.md` for *arr-stack integration and I2P settings.
